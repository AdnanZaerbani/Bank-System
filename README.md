Bank Management System

A small desktop banking application developed using C# and Windows Forms.

Overview

The Bank Management System is a desktop application developed to manage clients and basic banking operations.

The project was developed before working with relational databases and uses file-based storage for data persistence.

Features

- Client management
- Adding and editing client information
- Basic banking operations
- Data validation
- File-based data persistence
- Windows Forms user interface

Technologies

- C#
- .NET Framework
- Windows Forms (WinForms)
- File Handling
- Object-Oriented Programming

Purpose

This project was developed to practice:

- C# programming
- Object-Oriented Programming
- Windows Forms development
- File handling
- Data validation
- Application logic
